== [Spring] 가드에 구멍이 있을 때 킬스위치가 무엇을 건지는가 ==

  앞의 조건들은 가드가 완전한 화이트리스트(isFinite)라 NaN 도 Infinity 도 다 잡습니다.
  실무의 가드는 자주 불완전합니다. isInfinite 만 확인하거나 절댓값으로 상한을 보면
  Infinity 는 걸리는데 NaN 은 두 비교가 모두 false 라 그대로 지나갑니다.
  그 조건에서 킬스위치의 탐지원이 가드와 같은지 다른지로 결과가 갈립니다.

  먼저 Infinity 가 섞인 배치입니다(정상 100 + Inf 10 + NaN 10).
[조건 E] /orders/leaky · 구멍 난 가드 + 가드 연동 킬스위치
  201 접수     100건 (정상 100 / Inf 0 / NaN 0)
  422 거부       3건 (정상 0 / Inf 3 / NaN 0)
  503 킬스위치  17건 (정상 0 / Inf 7 / NaN 10)  <- 정상 0건이 부수 피해

[조건 F] /orders/leaky-independent · 같은 가드 + 독립 탐지 킬스위치
  201 접수     100건 (정상 100 / Inf 0 / NaN 0)
  422 거부       3건 (정상 0 / Inf 3 / NaN 0)
  503 킬스위치  17건 (정상 0 / Inf 7 / NaN 10)  <- 정상 0건이 부수 피해

  두 조건이 같습니다. 가드가 Infinity 는 잡으므로 그때 킬스위치가 켜지고
  뒤따르는 NaN 이 막힙니다. **가드가 못 잡는 값을 킬스위치가 막은 것이 아니라
  다른 종류의 비정상이 먼저 와서 대신 켜 준 것입니다.** 그 우연을 걷어냅니다.

  이번에는 NaN 만 있는 배치입니다(정상 100 + NaN 20). 가드가 아무것도 못 잡습니다.
[조건 E2] /orders/leaky · NaN 만 · 가드 연동 킬스위치
  201 접수     120건 (정상 100 / Inf 0 / NaN 20)
  422 거부       0건 (정상 0 / Inf 0 / NaN 0)
  503 킬스위치   0건 (정상 0 / Inf 0 / NaN 0)  <- 정상 0건이 부수 피해

[조건 F2] /orders/leaky-independent · NaN 만 · 독립 탐지 킬스위치
  201 접수     100건 (정상 100 / Inf 0 / NaN 0)
  422 거부       3건 (정상 0 / Inf 0 / NaN 3)
  503 킬스위치  17건 (정상 0 / Inf 0 / NaN 17)  <- 정상 0건이 부수 피해

  조건 E2 는 NaN 20건이 접수됐습니다. 킬스위치가 세는 것이 '가드가 거부한 건수'라,
  가드가 못 잡은 값은 거부되지 않으니 킬스위치도 세지 못합니다.
  조건 F2 는 NaN 접수 0건입니다. 탐지원을 접수 결과(기준가 이탈)로 옮기면
  가드가 무엇을 놓치든 셀 수 있습니다.

  **킬스위치의 값어치는 존재가 아니라 탐지원이 가드와 독립인가에서 나옵니다.**
  가드가 거부한 건수만 세는 킬스위치는 가드의 사본이지 두 번째 방어선이 아닙니다.
