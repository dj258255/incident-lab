# PostgreSQL PITR. 원 사례(GitLab 2017)와 같은 엔진으로 재현한다.
# PostgreSQL 17.5 (Debian 17.5-1.pgdg130+1) on aarch64-unknown

## 1) 베이스 백업 시점
  행 수 = 1000
  베이스 백업 완료: 24개 항목

## 2) 사고 직전 (여기까지 살려야 한다)
  행 수 = 1500
  시각 = 2026-07-31 01:00:17.530349+00

## 3) 사고 발생
  DELETE 후 행 수 = 1000  (1500에서 500건 사라짐)
  사고 트랜잭션 XID = 783
  사고 커밋 시각    = 2026-07-31 01:00:19.685293+00   ← pg_xact_commit_timestamp 로 정확히 얻은 값
  1초 뒤 시각       = 2026-07-31 01:00:20.685293+00   ← 눈대중으로 목표를 잡았을 때를 흉내낸다
  아카이브된 WAL = 36개

## 4) 복구 A: recovery_target_action 을 지정하지 않음 (기본 pause)
  목표 시각 = 2026-07-31 01:00:17.530349+00 (사고 직전)
    pg_ctl: server is running (PID: 24)
  복구 서버에서 조회: 1500
  복구 로그의 마지막 줄:
    2026-07-31 01:00:35.647 UTC [27] LOG:  recovery stopping before commit of transaction 783, time 2026-07-31 01:00:19.685293+00
    2026-07-31 01:00:35.647 UTC [27] LOG:  pausing at the end of recovery
    2026-07-31 01:00:35.647 UTC [27] HINT:  Execute pg_wal_replay_resume() to promote.
  pg_is_in_recovery = t
  → pg_wal_replay_resume() 을 불러 승격한다
  승격 후 행 수 = 1500 / pg_is_in_recovery = f

## 5) 복구 B: 목표 = 사고 커밋 시각 정각, inclusive 기본값(on)
    pg_ctl: server is running (PID: 24)
  행 수 = 1000
    2026-07-31 01:01:42.871 UTC [27] LOG:  recovery stopping before commit of transaction 784, time 2026-07-31 01:00:53.044446+00

## 6) 복구 C: 같은 목표 시각에 recovery_target_inclusive = off
    pg_ctl: server is running (PID: 23)
  행 수 = 1500
    2026-07-31 01:01:46.157 UTC [26] LOG:  recovery stopping before commit of transaction 783, time 2026-07-31 01:00:19.685293+00

## 7) 복구 D: 목표를 1초 늦게 잡고 recovery_target_inclusive = off
  목표 시각 = 2026-07-31 01:00:20.685293+00
    pg_ctl: server is running (PID: 24)
  행 수 = 1000

## 정리
  사고 전                         1500행
  사고 후                         1000행
  복구 A 사고 직전 목표(pause) 1500행
  복구 B 커밋 정각, inclusive=on 1000행
  복구 C 커밋 정각, inclusive=off 1500행
  복구 D 1초 늦게, inclusive=off 1000행

  B: 기본값 on 은 목표 시각의 트랜잭션을 포함한다. 사고가 다시 적용됐다.
  C: off 는 그 트랜잭션을 뺀다. 커밋 시각을 정확히 알 때만 통한다.
  D: 목표가 1초만 늦어도 off 는 아무것도 막지 못한다. inclusive 는 정각 한 건만 가른다.
