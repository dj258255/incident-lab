# 참조되지 않는 실행분

여기 있는 파일은 글과 세션 README 가 인용하지 않는 실행분입니다. 같은 이름에 ` 2` 가
붙어 있어 원본과 헷갈리기 쉬웠고, 값도 발행분과 다릅니다. 예를 들어
`window-matched 2.json` 은 DELETE 0.11초·DROP 0.12초로 발행값과 무관합니다.

지우지 않고 남기는 이유는 이 세션이 같은 실험을 여러 번 돌렸다는 사실 자체가 기록이기
때문입니다. 다만 리뷰어가 파일 이름으로 찾아 들어왔을 때 글을 반박하는 숫자를 먼저 만나지
않도록 위치를 옮겼습니다.

**글이 인용하는 것은 상위 디렉터리의 파일입니다.**
