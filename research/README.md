# 근거 조사 기록

카탈로그 각 세션의 근거(사건 실재 여부, 수치·연도·회사, E 등급 적정성)를 웹 원문으로 검증한 기록입니다.
판정 기준은 CATALOG.md 0-3절의 근거 등급 정의를 따릅니다.

기록 형식은 세션당 네 줄입니다. `주장`(카탈로그 행이 말하는 것) → `출처`(URL과 인용문, 원문을 직접 열어 확인했는지 검색 스니펫만 봤는지 표시) → `판정`(등급 유지·변경과 그 이유) → `메모`(글 쓸 때 주의할 점, 인용하면 안 되는 수치).

## 조사 결과 요약

59건 중 58건은 기존 등급이 타당했고, 1건은 등급을 올릴 근거를 찾았습니다. 등급과 별개로 카탈로그 서술 자체가 틀린 것 3건을 고쳤습니다.

**등급 변경**

- **A14 XID Wraparound [E2 → E1]**: Sentry가 2015-07-20 자사 장애를 블로그에 공개한 1차 포스트모템 확인.

**서술 수정 (등급은 유지)**

- **A11 세미싱크**: 근거로 적힌 PlanetScale 글은 자사 장애 회고가 아니라 기술 해설이었습니다. "PlanetScale이 겪은 장애"로 쓰면 왜곡입니다.
- **A20 데브시스터즈**: 원문은 24노드 중 16노드 영향이고 원인은 ballast 스크립트가 Block Device를 덮어쓴 사고입니다. 노드를 kill한 게 아니라 우리 재현이 축소판입니다.
- **A21 Figma**: "무중단"이 아니라 작업당 약 30초 부분 저하(요청 약 2% 드롭)였습니다.

셋 다 CATALOG 12절과 해당 행에 반영했습니다.

등급은 그대로 두되 글 쓸 때 조심할 것들은 각 파일의 `메모` 줄에 있습니다. 예를 들어 A05(VACUUM)는 현행 PG 공식 문서에 해당 경고 문장이 없어 공식 문서 인용 대신 실측으로 보여야 하고, R02는 "1분 내 복구" 수치를 원문에서 재확인하지 못해 "수 분 내"로 완화해야 합니다.
