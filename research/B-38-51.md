## B38 Log4Shell
- 주장: [E1] 로그의 `${jndi:ldap://...}` 치환으로 RCE, CVSS 10.0 (NVD 확인)
- 출처: NVD CVE-2021-44228 https://nvd.nist.gov/vuln/detail/CVE-2021-44228 : CVSS 3.1 기본점수 10.0(CRITICAL, AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H), "message lookup substitution 활성 시 LDAP 서버에서 로드한 임의 코드 실행", 영향 2.0-beta9~2.15.0, 2.16.0에서 제거 (원문)
- 판정: E1 유지 : CVE 번호·CVSS·JNDI/LDAP RCE 메커니즘·영향 버전 모두 NVD 원문과 일치. 별도로 CISA 긴급지침 ED 22-02·Apache 공식 어드바이저리 존재로 E1 근거 충분
- 메모: 재현 설계(취약버전+로컬 LDAP+콜백 관측)는 사실과 부합. 2.15.0은 기본 비활성이므로 재현엔 2.14.x 이하 사용 권장

## B42 xz-utils 백도어
- 주장: [E1] sshd 로그인 지연 이상으로 발견, git엔 없고 릴리스 tarball에만 있는 빌드 스크립트가 liblzma 하이재킹 (CVE-2024-3094)
- 출처: NVD CVE-2024-3094 https://nvd.nist.gov/vuln/detail/CVE-2024-3094 : CVSS 10.0 CRITICAL, xz(liblzma) 5.6.0/5.6.1, "liblzma 빌드 과정이 소스에 위장된 테스트 파일에서 사전빌드된 오브젝트 파일을 추출해 특정 함수 변조", sshd 등 링크된 소프트웨어 영향 (원문)
- 판정: E1 유지 : CVE·버전·sshd 영향·"위장 테스트 파일→빌드 시 오브젝트 추출" 메커니즘이 원문과 일치. tarball-only 빌드 스크립트 서술 정확
- 메모: "0.3→0.8초"는 발견자(Andres Freund) 원 보고의 "약 0.5초 지연 증가"와 정합(오차 0.5초). 발견 색채 디테일이므로 인용 시 "약 0.5초 느려진 sshd"로 완화 권장. 실 백도어 재현 금지 유지

## B40 Capital One SSRF → IMDS
- 주장: [E1] WAF의 SSRF로 EC2 메타데이터 질의해 IAM 자격증명 획득, 1억 명 유출, IMDSv2 도입 계기
- 출처: Krebs on Security(2019-08) https://krebsonsecurity.com/2019/08/what-we-can-learn-from-the-capital-one-hack/ : "잘못 설정된 WAF가 요청을 메타데이터 서비스로 릴레이 → 임시 자격증명 회수", 과도한 IAM 권한으로 S3 접근, "100M+ / 106M명 영향" (2차·권위)
- 판정: E1 유지 : SSRF→메타데이터→IAM 자격증명→유출 메커니즘 일치. "1억 명"은 실제 106M(미국 100M+캐나다 6M)과 정합. OCC 벌금·DOJ 기소 등 규제 문서 존재로 E1 근거 충분
- 메모: 엄밀히는 "SSRF + 과도 IAM 권한 + IMDSv1" 복합 원인. IMDSv2가 이 사건 직후 나온 건 사실. 재현 설계(목 메타데이터 서버) 타당

## B45 삭제 스크립트 (Atlassian 2022)
- 주장: [E1] 스크립트가 app ID 대신 site ID를 받아 883개 사이트(775 고객) 영구 삭제, 소프트딜리트 부재로 복구 최대 14일
- 출처: Atlassian 공식 PIR https://www.atlassian.com/engineering/post-incident-review-april-2022-outage : 삭제 API가 site/app ID 둘 다 받아 입력 검증 없이 신뢰, 883 사이트/775 고객, 2022-04-05 07:38~08:01 UTC, 소프트딜리트 없음, 최대 복구 14일(4/18 완료) (원문)
- 판정: E1 유지 : 883/775·site ID 혼동·무검증·소프트딜리트 부재·14일 복구 모두 공식 PIR과 정확히 일치
- 메모: RPO 5분 이내로 데이터 유실은 최소. 재현 설계(잘못된 스코프+dry-run/소프트딜리트/타입검증 전후) 정확
